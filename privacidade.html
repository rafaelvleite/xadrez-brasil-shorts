Política de Privacidade — Xadrez Brasil Shorts Uploader

Última atualização: 8 de novembro de 2026

O Xadrez Brasil Shorts Uploader é uma ferramenta interna do canal Xadrez Brasil no YouTube. Ela roda localmente no computador do dono do canal e serve apenas para publicar, no próprio canal, os Shorts que ele mesmo produz. Não é oferecida a outras pessoas.

Dados acessados

Com a autorização do dono do canal (login do Google), a ferramenta usa os Serviços de API do YouTube com três permissões:

  • youtube.upload — enviar vídeos ao canal e definir a capa (thumbnail);
  • youtube.readonly — confirmar qual canal foi autorizado, descobrir a categoria usual dos vídeos e acompanhar o processamento dos envios;
  • youtube.force-ssl — corrigir o título, a descrição e as tags de um Short que a própria ferramenta já enviou, quando o dono do canal pede.

Ela não lê comentários, inscritos, mensagens, dados de pagamento nem dados de outras pessoas, e não apaga vídeos.

Como os dados são usados e guardados

  • Os tokens de acesso ficam apenas no computador do dono do canal, em arquivo com permissão restrita.
  • Os dados obtidos do YouTube (id do canal, id e situação dos vídeos enviados) são usados só para agendar e conferir os próprios envios, e ficam guardados localmente.
  • Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos.
  • O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogar o acesso

A autorização pode ser revogada a qualquer momento em myaccount.google.com/permissions. Apagar a pasta de credenciais da ferramenta remove os tokens guardados no computador.

Serviços de API do YouTube

Este aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é descrito na Política de Privacidade do Google.

English summary. Xadrez Brasil Shorts Uploader is an internal tool used only by the owner of the Xadrez Brasil YouTube channel to upload and schedule the channel's own Shorts. It uses the YouTube API Services with the youtube.upload, youtube.readonly and youtube.force-ssl scopes to upload videos, set thumbnails, confirm the authorized channel, check processing status and correct the title, description and tags of Shorts it has uploaded. It never deletes videos or reads comments. Tokens and data stay on the owner's computer; nothing is sold, shared or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Revoke access at myaccount.google.com/permissions. By using this app you agree to the YouTube Terms of Service; see also the Google Privacy Policy.
